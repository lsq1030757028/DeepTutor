## manager 自决三项（报备，可推翻）

1. **触点计数口径**统一为「登记表新增行数」，并新增要求：既有触点**性质加深**必须单独报备。
   依据：交互稿按"碰到的文件数"数 4 处、登记表按新增行数数 0 处，两口径并用会让预算失去意义。
   证伪信号：出现"没有新增登记行但上游同步反复冲突"的情况，说明该口径漏计真实风险。
2. **Dockerfile 触点加深接受**（从 2 行 COPY → 安装一套运行时），条件：安装段独立成可整块删除的 fork 块。
   依据：拒绝等于 0012（TAPD 进容器+stdio，用户 2026-08-08 拍板）事实作废。
   证伪信号：上游同步时该块反复冲突或阻断合并。
3. **M2 数据分区只做目录布局分区**，账号级鉴权隔离并入上线前置闸（与"线上演进四件套"同批）。
   依据：推荐通道拿不到可信 owner 身份，此刻做出来是假隔离。
   证伪信号：M2 期间出现真实多用户并发使用需求。
