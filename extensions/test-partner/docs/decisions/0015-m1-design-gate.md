## 线上演进四件套（用户提出线上多用户部署诉求后 manager 建议、用户确认，登记为**上线前置闸**）

M1 拓扑不为线上负责；DT 部署到线上服务器并开放多用户前，以下四件必须完成，缺一不得开放：

1. 账号级数据分区（0009 实现层，M2）
2. 执行任务队列：并发治理从单机"上限 2 + 定期回收"升级为队列制
3. 出网安全：执行器代表用户向任意 base_url 发请求构成 SSRF 面——目标白名单 + 禁内网网段 + 按用户限流
4. trace/证据落每用户分区

架构保证：执行器已隔在独立服务边界后（test-partner 独立进程），线上化 = 部署形态替换（sidecar → 独立执行器容器/runner 池），闭环逻辑不动。
