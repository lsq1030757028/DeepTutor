范本与预设 prompt

范本决定 AI 起草成什么形状，预设 prompt 决定它怎么读 HAR。两者都可改，改坏了能还原。

看看/修改预设 prompt
这是你个人的预设，不影响别人
为什么是「整段 + 固定范本 + 可编辑表单」三件合一：范本的五个字段就是表单的五个格子—— 读起来是一段完整的场景描述，改起来是填空，AI 起草时也知道该往哪几个格子里填。 自由文本框会让人不知道写什么，纯勾选又表达不了「库存不足不能超卖」这种业务话。
